# Role ownership

Task/approval sequence: policies/GIT-CHECKLIST.md (sole source). Model/routing floor: project AGENTS.md and .codex/agents/*.toml. Developer owns scoped implementation, tester independently assesses risk when needed, architect handles substantial design decisions, designer handles visual decisions. Coordinator owns Git and integration; one writer per scope. Do not run all roles for every task. Routine commits need no subagent. Pass goal, scope, affected paths and acceptance criteria; return concise findings and evidence, not full logs/history.
